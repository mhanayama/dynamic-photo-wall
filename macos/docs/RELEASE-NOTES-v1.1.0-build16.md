# macOS v1.1.0 build 16 — 同期表示の描画負荷軽減

2026-10-19。build 15の再起動後もCPUが下がらないという報告とsampleに基づき、同期表示の描画を変更したApple Silicon用ローカルビルドです。GitHub Releaseへは未公開です。

## build 15からの変更

- 同期表示の写真をCore Animationの画像contentsとして保持し、各フレームでのbitmap再描画をなくします。動作中は位置・倍率・不透明度を更新します。
- 背景の補間は保持した画像の不透明度で行います。同じ不透明PNGが続く区間はレイヤー属性も更新しません。透明な背景のsource-over合成は従来どおり維持します。
- ウィンドウの前面化は表示開始と非表示からの復帰時に限ります。
- 写真の向き、角丸、clip、スパンcrop、独立した写真フェードと場面全体のフェードを維持します。16msの進行時計、同期PNGの内容・色補正・wire時刻、通信と復旧処理は維持します。

[測定結果と制約](RENDERING-MEASUREMENTS-2026-10-19.md)、[描画経路と検証](RENDERING-PERFORMANCE.md)を参照してください。合成画像の独立ウィンドウでの改善値は、通常アプリの全画面表示の改善率ではありません。

## 配布と更新

Apple Silicon（arm64）、macOS 27.0以降。アドホック署名です。`release/macos/arm64/`に展開済みAPP・ZIP・DMG・SHA256SUMSを置き、旧配布物は`artifacts/macos/package/previous-release.*/`へ退避します。

稼働中のbuild 15は自動で切り替わりません。いったんアプリを終了し、`release/macos/arm64/DynamicPhotoWall.app`から起動し直してください。`/Applications`のコピーは今回の更新対象に含めていません。
