# macOS v1.1.0 build 15 — ローカル配布用ビルド

2026-10-19。Issue #1のローカル描画改善を含むApple Silicon用ビルドです。`release/macos/arm64/`のAPP／ZIP／DMGを更新しました。GitHub Releaseへは未公開です。

## build 14からの変更

- 静止Galleryの構成が変わらなければ背景画像を再生成せず、写真交換・配置変更・画像準備完了などを契機に更新します。
- Pan/Zoom/Scrolling Galleryや交換フェード中は、実際の動き・不透明度の変化に応じて更新します。
- ローカル背景の色追従を保持した画像の表示補間へ分離し、静止後も追加の画像生成なしで最終色へ到達します。
- 顔保護を含む動きの計画・静止Gallery配置をキャッシュし、同じ写真への無条件の再描画要求を抑えます。
- 生成中の最新変更を保持し、停止・一時停止後に古い生成結果が公開されないようにします。

同一fixtureの静止Gallery比較は平均CPU 22.28%→12.05%（各3回、準備5秒＋測定10秒）、測定区間の背景生成80回→0回/10秒でした。独立した960×540の測定ウィンドウの結果であり、通常の全画面表示や既存の同期表示に同じ改善率を保証する値ではありません。[測定条件と結果](RENDERING-MEASUREMENTS-2026-10-19.md)を参照してください。

同期PNG・wire時刻・受信時の色補正と既存の同期描画経路は維持しています。同期側は静止/一時停止相当でも再描画が続くことを確認しており、この負荷軽減は次の対応対象です。

## 配布と更新

Apple Silicon（arm64）、macOS 27.0以降。アドホック署名で、Developer ID署名・公証は行っていません。同じRelease archiveからAPP・ZIP・DMGを作ります。

実行中の旧版を終了してから、DMGまたはZIPの`DynamicPhotoWall.app`をApplicationsへコピーし、起動してください。今回のローカル配布物更新そのものは、`/Applications`の旧版と稼働中プロセスを置き換えません。
