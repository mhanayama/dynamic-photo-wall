# Mac v1.1.0 build 14 — 試用版

この旧版のReleaseは下書きで保管します。現在の配布物は[2026-10-20更新のbuild 17](RELEASE-NOTES-2026-10-20.md)を参照してください。

LAN内の写真共有と同期再生を試せるMac版です。

## 変更点

- Zoomで写真の構図を保ちながら、顔が見える位置へ調整します。
- 同期中のGalleryが途中で止まる問題を修正しました。
- 同期再生の描画負荷を軽減しました。

## インストール・更新

Apple Silicon、macOS 27.0以降に対応します。
旧版を終了し、DMG内のアプリをApplicationsへコピーしてください。ZIPにも同じアプリを含みます。
アドホック署名で、Appleによる公証は行っていません。

build 10以前の通信設定がある場合は、「ネットワーク」で「新しい通信設定を作成」を選び、接続し直してください。
写真・表示設定は引き継げます。通信の鍵は端末内の専用ファイルへ保存します。

Windowsとの同期には、2026-10-20更新のWindows版を利用できます。
端末間の同期、画面の抜き差し、スリープ復帰、長時間運転の確認は継続中です。
