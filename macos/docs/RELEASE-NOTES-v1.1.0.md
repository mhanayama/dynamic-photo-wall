macOS v1.1.0（build 4）のApple Silicon専用リリースです。v1.0.1から、複数画面の再生と写真の配置を拡張しました。

### 追加・改善

- 複数のディスプレイを選択し、同じグループの画面をつないだ表示、別グループ・独立画面ごとの再生に対応しました。配置はドラッグ・スナップ・数値入力で調整できます。
- 設定を「一般」「使用ディスプレイ」「画面グルーピング」「写真」「表示モード」「動き」「見た目」に整理しました。空グループの保存とグループの削除にも対応します。
- 写真の登録や設定の保存なしで、現在の配置のテストパターンを即表示できます。終了時は適用済みの写真再生と手動の一時停止状態へ戻ります。
- 写真アプリのアルバムを写真ソースへ追加できます。選択時に自動検索し、フォルダーとの併用やアルバムだけでの再生にも対応します。
- 最大の顔の反対側から縦横Panを開始する設定を追加しました。顔停止・Zoomの顔優先設定とは独立して切り替えられます。
- 5モードそれぞれに「ディスプレイごとに表示」を追加しました。グループ内のモード・時計・pause・Next・フェードは共有します。
- スパンGalleryと縦Panで、検出した顔が画面の境界に重ならないよう配置します。Gallery交換時は既存の写真を滑らかに移動し、交換写真だけをフェードします。
- 壁全体への拡大率が上限を超える小さい縦写真は、同じ写真が各接続画面で適性を満たす場合、自動で同一写真をミラー表示します。
- 顔を保護したGalleryで、通常の写真間隔と基準線を保つ列配置を優先します。ランダム再生では顔位置がキャッシュ済みの候補だけを比較し、隙間・縮小・偏りを改善できる場合に再抽選します。
- 旧設定・フォルダーブックマーク・写真アルバムの選択を保持します。未接続画面の領域を残し、影響するグループだけを復旧します。画像キャッシュはアプリ全体で共有します。

### 対応環境・インストール

- Apple Silicon（arm64）、macOS 27.0以降。
- 実行中の旧版を終了し、DMG内のアプリをApplicationsへコピーしてください。ZIPも同じアプリを含みます。
- アドホック署名です。Developer ID署名・公証は行っていません。
- 設定の変更は「保存して適用」で確定し、取消や設定画面を閉じる操作で未保存の変更を破棄できます。
- Dock／メニューバーはmacOS側の設定に従います。PC間同期・LANペアリングは含みません。
