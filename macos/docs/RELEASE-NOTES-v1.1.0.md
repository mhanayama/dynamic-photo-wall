# Mac v1.1.0 — 正式版

このページは初回公開のbuild 4の記録です。現在の配布物は[2026-10-20更新のbuild 17](RELEASE-NOTES-2026-10-20.md)を参照してください。

端末内の写真を再生するMac版です。ネットワーク機能を試す場合は、build 14の試用版をお使いください。

## 変更点

- 複数画面をつなげた表示と、画面ごとの独立再生に対応しました。
- 「写真」アプリのアルバムを選べるようになりました。
- 顔が見える構図や、画面の境目を避ける配置を改善しました。
- 写真なしで画面の配置を確認できるテストパターンを追加しました。

## インストール・更新

Apple Silicon、macOS 27.0以降に対応します。
旧版を終了し、DMG内のアプリをApplicationsへコピーしてください。ZIPにも同じアプリを含みます。
写真・表示設定は引き継げます。アドホック署名で、Appleによる公証は行っていません。

異なる表示倍率の画面、画面の抜き差し、スリープ復帰、長時間運転の確認は継続中です。
