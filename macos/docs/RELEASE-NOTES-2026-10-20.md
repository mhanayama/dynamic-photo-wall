# Mac v1.1.0 — 2026-10-20更新

同期再生のカクつきを改善し、写真と背景の描画負荷を軽減した更新です（build 17）。

## 変更点

- 同期再生中の写真の動きを滑らかにし、次の表示を準備するときの引っかかりを減らしました。
- 写真・背景の不要な描き直しを減らし、複数画面での共有再生を軽くしました。
- Galleryの写真交換が続くよう修正しました。写真の構図を保つZoomや、背景の滑らかな色変化も含みます。
- フォルダーと「写真」アプリのアルバム、複数画面のグルーピング、LAN内の写真共有に対応します。

## インストール・更新

Apple Silicon搭載Mac、macOS 27.0以降に対応します。
メニューから旧版を終了し、DMG内のアプリをApplicationsへコピーしてください。ZIPにも同じアプリを含みます。
写真と保存済みの設定は引き継げます。アドホック署名で、Appleによる公証は行っていません。

## 確認状況

単体テストと配布物の検証を行い、手動テストで同期再生のカクつき改善を確認しました。
ネットワーク機能は試験用です。複数端末の網羅的な同期、異なる表示倍率、画面の抜き差し、スリープ復帰、長時間運転の確認は継続中です。
