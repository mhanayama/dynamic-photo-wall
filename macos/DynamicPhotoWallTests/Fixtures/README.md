# Parity fixtures

- `WindowsParity.json`: generated by the repository's Windows Core implementation with `dotnet run --project tests/ParityVerifier -- --generate macos/DynamicPhotoWallTests/Fixtures/WindowsParity.json`. Both C# and Swift verify the same committed expected values. Regenerate only after reviewing a deliberate behavior change.
- `astronaut.png`: NASA photograph of Eileen Collins, distributed by [scikit-image v0.19.3](https://github.com/scikit-image/scikit-image/blob/v0.19.3/skimage/data/astronaut.png). The [dataset documentation](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut) identifies it as public domain. Used only for Vision/EXIF tests; not shipped in the app target.
- `hopper.webp`: public-domain US Navy photograph of Grace Hopper, from [Pillow 11.3.0 test images](https://github.com/python-pillow/Pillow/blob/11.3.0/Tests/images/hopper.webp). Used to test a real WebP container (128×128). Not shipped in the app target.

JPEG and HEIC/HEIF fixtures are encoded during tests into temporary directories. No user photo or production setting is used.

As of 2026-10-17, the existing 36 motion cases explicitly set `faceAwarePanDirection: false` to preserve the macOS v1.0.1 baseline while Windows defaults to the new face-directed behavior. The generator uses the same setting. The new `WindowsDelta.json` suite adds 52 direction/boundary motion cases and 4 face-safe Gallery layouts without regenerating this baseline; see [the handover](../../WINDOWS_DELTA_HANDOVER.md). Existing expected coordinates remain unchanged.

`WindowsDelta.json` is generated by `dotnet run --project tests/ParityVerifier -- --generate-delta macos/DynamicPhotoWallTests/Fixtures/WindowsDelta.json`. Both `DeltaVerifier.cs` and `WindowsDeltaFixtureTests.swift` compare the committed coordinates, including vertical `frameTop`. It covers direction ON/OFF, both pan axes, face stopping, multiple faces, side-by-side/stacked/gapped displays and a disconnected tile. D09 adds 4 Gallery loss/replacement cases (472 C# assertions total). Two of the four Gallery layout expectations intentionally change for compact common-baseline rows; the 52 motion expectations and the older WindowsParity baseline remain unchanged. The standard verify script checks both fixture files. Regenerate only after reviewing the behavior change.
