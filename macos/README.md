# Dynamic Photo Wall — Mac

Apple Silicon搭載Mac、macOS 27.0以降に対応するデスクトップ・フォトギャラリーです。

[ダウンロード](https://github.com/mhanayama/dynamic-photo-wall/releases/tag/macos-v1.1.0) / [10月20日の更新内容](docs/RELEASE-NOTES-2026-10-20.md)

## はじめる

1. DMGを開き、`DynamicPhotoWall.app`をApplicationsへコピーします。
2. アプリを起動し、必要なアクセス権限を許可します。
3. 「使用ディスプレイ」で表示する画面を選びます。
4. 「写真」でフォルダー、または「写真」アプリのアルバムを追加します。
5. 「保存して適用」を押します。

JPEG・PNG・WebP・HEIC・HEIFに対応します。iCloud上の写真は表示するときにダウンロードします。
配布アプリはアドホック署名で、Appleによる公証は行っていません。

## 表示を変える

表示モードはGallery、Scrolling Gallery、縦パン、横パン、Zoomの5つです。
「表示モード」と「動き」で調整できます。

複数の画面をつなげたい場合は、「画面グルーピング」で同じグループへ割り当てます。
画面ごとに別々に再生したい場合は「独立して表示」を選びます。
保存前にテストパターンで配置を確認できます。

設定画面を閉じても再生は続きます。一時停止・次の構成・設定・終了はメニューバーから操作します。
Dockとメニューバーの表示はmacOSの設定に従います。

## 更新する

メニューから旧版を終了し、Applicationsのアプリを新しい版へ置き換えます。
保存済みの写真・表示設定は引き継げます。権限の確認が出た場合は許可してください。

build 10以前の通信設定がある場合は、「ネットワーク」で「新しい通信設定を作成」を選び、接続し直してください。
設定・キャッシュ・ログは、アプリ専用のsandbox内に保存されます。配布物には写真・個人設定を含みません。

## 写真の共有

試験用の「ネットワーク」でオンラインモードを有効にすると、選択した写真と顔データをLAN内の接続先へ送ります。
接続要求は受信側の確認なしで受け入れます。クラウドへの写真送信はありません。
通信の鍵は端末内の専用ファイルに保存します。[保存方式](docs/LOCAL-NETWORK-STORAGE.md)を参照してください。

同期再生のカクつき改善は手動確認済みです。複数端末の網羅的な同期、異なる表示倍率、画面の抜き差し、スリープ復帰、長時間運転の確認は継続中です。

細かい設定や動作仕様は[詳細リファレンス](REFERENCE.md)、ビルド方法は[開発ガイド](../docs/DEVELOPMENT.md)を参照してください。
