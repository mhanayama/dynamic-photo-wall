# Dynamic Photo Wall — Windows

Windows 11 x64用のデスクトップ・フォトギャラリーです。

[ダウンロード](https://github.com/mhanayama/dynamic-photo-wall/releases/tag/windows-v0.1.0) / [10月20日の更新内容](docs/RELEASE-NOTES-2026-10-20.md)

## はじめる

1. ZIPを展開して`DynamicPhotoWall.exe`を起動します。.NETのインストールは不要です。
2. 「使用ディスプレイ」で表示する画面を選びます。
3. 「写真」で写真フォルダーを追加します。
4. 「保存して表示開始」を押します。

設定画面を閉じても再生は続きます。一時停止・次の構成・設定・終了は、タスクトレイから操作できます。
JPEG・PNG・WebPに対応します。HEIC・HEIFにはWindowsの対応コーデックが必要です。

## 表示を変える

| やりたいこと | 設定する場所 |
|---|---|
| 複数の画面をつなげる | 「画面グルーピング」で同じグループへ割り当てる |
| 画面ごとに別々に再生する | 「画面グルーピング」で「独立して表示」を選ぶ |
| 特定のモードだけ各画面に別の写真を出す | 「表示モード」で「ディスプレイごとに表示」をON |
| 写真の動きや切り替えを変える | 「表示モード」と「動き」 |
| タスクバーを隠す | 「使用ディスプレイ」で対象画面を指定する |
| ログイン時に起動する | 「一般」で自動起動を設定する |

表示モードはGallery、Scrolling Gallery、縦パン、横パン、Zoomの5つです。
画面の配置は「画面グルーピング」で調整でき、保存前にテストパターンで確認できます。
Windows自体の壁紙や画面配置は変更しません。

## 更新する

タスクトレイから旧版を終了し、新しいZIPを展開して置き換えます。
写真フォルダーの選択や表示設定は引き継げます。EXEの場所を変えた場合は、自動起動を設定し直してください。

設定・キャッシュ・ログは`%LOCALAPPDATA%\DynamicPhotoWall`に保存されます。
配布ZIPには写真や個人設定を含みません。本体は署名なしです。

## 写真の共有

試験用の「ネットワーク」でオンラインモードを有効にすると、LAN内の端末へ接続できます。
選択した写真と顔データを接続先へ送信します。接続要求は受信側の確認なしで受け入れます。
クラウドへの写真送信はありません。

端末間の同期、混在DPI、画面の抜き差し、長時間運転の確認は継続中です。

細かい設定や動作仕様は[詳細リファレンス](REFERENCE.md)、ビルド方法は[開発ガイド](../docs/DEVELOPMENT.md)を参照してください。
