# Windows v0.1.0 — 2026-10-19更新

Windows 11 x64向けのランタイム同梱版です。既存の`windows-v0.1.0`リリースのEXE・ZIP・チェックサムを最新ソースで更新します。初回公開時のタグは保持し、今回のソースは配布物の`BUILD-INFO.txt`に記録します。

## 主な変更

- トレイの右クリックメニューで`Accessibility`の読み込みが失敗する問題を対処しました。単一EXE内のマネージドライブラリも起動時に展開し、ホストEXEの差し替え後も依存を読み込めるようにしました。メニュー表示の失敗は局所的に記録し、スライドショーを停止しません。適用にはアプリの再起動が必要です。
- Galleryは、表示中の写真・位置・大きさを保ちながら1枚ずつの交換を継続します。Scrolling Galleryも終端位置と速度を引き継ぎます。
- Galleryの短辺サイズを保つ配置、最大20枚、5〜10秒の交換間隔、公平な写真の選択に対応します。
- モード抽選をギャラリー80／パン・ズーム20の2系統に整理しました。同じGalleryが再当選した場合は表示を保って再抽選します。
- Zoomは写真の構図を保ち、全顔が収まるための必要最小限の位置補正を行います。
- 動的背景の色補正・連続補間、表示切替時の前の写真と背景の保持、オンライン再生中のデスクトップ描画順を改善しました。
- 試験用ネットワーク機能、接続中の写真ソース表示、ピアの接続解除、共有画面配置を追加しました。
- 本体のMITライセンス、依存ライブラリのライセンス、配布用README、コミットと依存バージョンを記録するビルド情報を整備しました。

## 配布物と更新

- `DynamicPhotoWall-windows-x64.zip`: EXE・README・MITおよび依存通知・`BUILD-INFO.txt`を同梱します。展開して利用してください。
- `DynamicPhotoWall.exe`: 同じ単一EXEです。.NETの別途インストールは不要です。再配布にはZIP内のライセンス類も添付してください。
- `SHA256SUMS.txt`: EXEとZIPのSHA-256です。PowerShellの`Get-FileHash -Algorithm SHA256`で確認できます。

旧版をタスクトレイから終了してから置き換えてください。`%LOCALAPPDATA%\DynamicPhotoWall`の設定・キャッシュと写真フォルダー設定は引き継ぎます。EXEを移動した場合はログオン自動起動を設定し直します。写真・個人設定・鍵・キャッシュは配布物へ含めません。

## 検証範囲

今回の検証結果は[配布検証記録](RELEASE-VERIFICATION-2026-10-19.md)に記録します。通常の検証はCLIと単体テストで行い、GUI操作付きの自動テストは実行しません。

オンラインモードは実機確認用です。Mac↔Windows間のLAN接続と同期表示、混在DPI、実ケーブル抜差し、長時間運転の実機受け入れは未完了です。macOSの配布物は今回更新しません。本体は署名なしです。
