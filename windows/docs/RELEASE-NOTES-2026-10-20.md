# Windows v0.1.0 — 2026-10-20更新

写真の再生と背景描画の負荷を軽減した更新です。

## 変更点

- 写真・背景の不要な描き直しを減らし、複数画面での共有再生を軽くしました。
- 表示サイズに合わせて写真を読み込み、画像を再利用するようにしました。
- Galleryの写真交換と、終端付近のフェードが最後まで続くよう修正しました。
- 写真の構図を保つZoom、背景の滑らかな色変化、トレイメニューの安定化も含みます。

## インストール・更新

Windows 11 x64用です。旧版をタスクトレイから終了し、ZIPを展開して`DynamicPhotoWall.exe`を起動してください。
.NETのインストールは不要です。保存済みの設定は引き継げます。本体は署名なしです。

## 確認状況

単体テストと配布物の検証を行っています。実機で描画負荷の低下も観測しました。
端末間の同期、混在DPI、画面の抜き差し、長時間運転の確認は継続中です。ネットワーク機能は試験用です。
