## 追加修正

1. `WallController`が同期再生へ移行する際、ローカルセッションの停止完了後にローカル画像LRUを解放する。同期表示中の画像とネットワーク写真キャッシュは維持する。
2. `SharedPhotoDrawing`の子Drawingは、opacityが正で、変換後の写真がclipへ寄与できる間だけ親へ接続する。画面外・透明時は外し、画面に入る際に同じDrawingを再接続する。境界の補間・丸めのため1pxの余裕を取る。CPUで先読みした画像、共有ready条件、時刻評価、参照描画経路、巻き戻し・継続を維持する。

第2項は描画ツリーへ渡す不要なリソースと変更を減らす修正候補。WPF内部での実転送量、GPU使用率・電力の改善幅は未測定。decoded画像の全件保持をやめる変更でもない。第1項の103.68MiBもキャッシュ会計値であり、Private Bytesが同じだけ直ちに減るという保証ではない。
