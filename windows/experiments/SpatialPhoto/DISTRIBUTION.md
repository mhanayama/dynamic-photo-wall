# Spatial Photo Test — Windows x64 強度調整版

`SpatialPhotoTest.exe`をダブルクリックし、画像をウィンドウへドラッグ＆ドロップしてください。深度を自動生成し、視差を付けて再生します。EXEのアイコンへ画像をドロップして起動することもできます。

- JPEG／PNG／WebPを1枚ずつ使用します。生成中に別の画像をドロップすると、完了後に最後の1枚を処理します。
- 「写真を選択して深度生成」ボタンからも開けます。
- 片道／往復、初期方向、速度、強さを調整できます。「深度 / 写真を切り替え」で生成された深度を確認できます。
- 視差の強さは0〜100%（既定50%）です。強い設定では輪郭の歪みも増えるため、見ながら調整してください。以前の角度表記は実際のカメラ角度ではなかったため廃止しました。
- 「左端」「右端」や手動視点スライダーで、視点だけを瞬時に切り替えて比べられます。自動再生へ戻すには「視点を手動で確認」をOFFにするか「最初から再開」を押してください。
- 同じ写真はキャッシュから再生します。写真を編集した場合は再生成します。
- 元画像は変更せず、写真を外部へ送信しません。

Windows x64・Direct3D 12対応GPUが必要です。.NETの別途インストールは不要です。`models`フォルダーには深度推定モデルが入っています。移動する場合は、**このフォルダー全体を一緒に移動**してください。

実験機能のためGPU負荷・消費電力・温度・ファン動作が増える場合があります。ゲームとの同時利用は推奨しません。通常のWindows権限で起動してください。

単眼写真からの2.5D視差表現です。左右眼別のステレオ画像や真の3D復元には対応していません。隠れた背景の復元は行わないため、輪郭に歪みが出る場合があります。

キャッシュはリポジトリ内では`artifacts/windows/spatial-photo/cache/`、フォルダーを単独で持ち出した場合は`%LOCALAPPDATA%/DynamicPhotoWall.SpatialPhotoTest/cache/`へ保存します。モデルと使用ライブラリのライセンスは`licenses/`を参照してください。
